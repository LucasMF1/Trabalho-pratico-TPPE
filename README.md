## Compilar e testar

Use o JDK 17 e coloque os arquivos JAR indicados em `trabalhoPratico/libs/LEIAME.txt` na pasta `trabalhoPratico/libs/`. As bibliotecas não estão incluídas no repositório de origem.

```bash
cd trabalhoPratico
./build.sh
./test.sh
```
